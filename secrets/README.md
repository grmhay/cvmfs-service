# Secrets

Only `*.enc.yaml` is committed. Plaintext shapes (create, fill, `sops --encrypt --in-place`):

`publisher.enc.yaml` — decrypted on the control node by the `cvmfs_publisher` role:
```yaml
minio_access_key: ""        # service account from server/minio/RUNBOOK.md
minio_secret_key: ""
nixbuild_private_key: |     # ssh key the Publisher uses to reach pi5/pi6 (ssh-keygen -t ed25519)
  -----BEGIN OPENSSH PRIVATE KEY-----
  ...
deploy_key_private: |       # read-only deploy key for github.com/grmhay/cvmfs-service
  ...
```

`masterkey.enc.yaml` — the repository **master key** (`/etc/cvmfs/keys/nix.hayweb.org.masterkey`).
Generated by `cvmfs_server mkfs`; encrypted here and **removed from the Publisher** afterwards.
It is only ever decrypted onto the Publisher for `cvmfs_server resign` (docs/runbooks/resign.md).
```yaml
masterkey: |
  -----BEGIN RSA PRIVATE KEY-----
  ...
```

The repository **public key** (`nix.hayweb.org.pub`) is not a secret: it is committed at
`ansible/roles/cvmfs_client/files/nix.hayweb.org.pub` and shipped to every host.
