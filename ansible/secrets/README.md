# Secrets

Only `*.enc.yaml` is committed. This directory sits under `ansible/`, so the ciphertext ships inside
every tagged collection. Plaintext shapes are below. Add a key to an existing file with
`sops --set` on any host with the age key (ADR 0005: every non-Proxmox host has `sops`, `age` and the
key at `~/.config/sops/age/keys.txt`).

`publisher.enc.yaml` — decrypted on the control node by the `cvmfs_publisher` role (Semaphore on
pi5, template 7; `sops_age_key_file` finds the key even though Semaphore changes `HOME`). It is
created by `server/minio/create-publisher-key.sh` (server/minio/RUNBOOK.md §2), which writes the
two MinIO keys; the others are added later with `sops --set`:
```yaml
minio_access_key: ""        # the cvmfs-publisher service account
minio_secret_key: ""
nixbuild_private_key: |     # ssh key the Publisher uses to reach pi5/pi6 (ssh-keygen -t ed25519); public half in nix_builder's defaults
  -----BEGIN OPENSSH PRIVATE KEY-----
  ...
github_access_token: ""     # fine-grained, grmhay/vm-service Contents read-only (#37); has an expiry
```

To rotate `nixbuild_private_key`: `sops set` the new private key, make its public half
`nix_builder_authorized_key` and move the old one to `nix_builder_revoked_keys` (both in
`roles/nix_builder/defaults/main.yml`), tag, then run `cvmfs: publisher` before `cvmfs: builders`, with no
Profile change merged in between (a build in that gap cannot reach the Builders).

`masterkey.enc.yaml` — the repository **master key** (`/etc/cvmfs/keys/nix.hayweb.org.masterkey`).
Generated by `cvmfs_server mkfs`; encrypted here and **removed from the Publisher** afterwards by
`nix run .#masterkey-escrow` (publish/masterkey-escrow.sh, docs/runbooks/publisher-bootstrap.md).
The `cvmfs_publisher` role installs this ciphertext on the Publisher (root only), where
`cvmfs-resign.service` decrypts it weekly into tmpfs for `cvmfs_server resign` (docs/runbooks/resign.md).
```yaml
masterkey: |
  -----BEGIN RSA PRIVATE KEY-----
  ...
```

The repository **public key** (`nix.hayweb.org.pub`) is not a secret: it is committed at
`ansible/roles/cvmfs_client/files/nix.hayweb.org.pub`, ships inside the collection, and is shipped to
every host. The Publisher's run prints it after mkfs (docs/runbooks/publisher-bootstrap.md).
